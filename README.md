# Tailwind CRM

A single-page CRM UI inspired by Asana / ClickUp using **HTML + CSS + Vue (script tag)** and Tailwind utility styling.

## Features

- AJAX-loaded DataTable with:
  - global search
  - pagination
  - per-column filters
  - show/hide columns (ColVis)
  - CSV export
  - bulk row actions
  - quick inline cell editing
- CRM intake form with 15+ fields (text, number, phone, dropdowns, geolocation, radio, checkboxes)
- Detail page with multiple tabs and quick field updates

## Run

Open `index.html` directly in a browser.
